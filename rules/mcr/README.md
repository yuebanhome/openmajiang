# 国标规则插件

规则标识为 `openmajiang.mcr@1.0.0`，来源为 WMO《麻将竞赛规则》2014 年第二版，线上补充为 `om-mcr-1`。来源 PDF 的 SHA-256 及算番库来源、许可、适配点见 `scoring/`。规则状态及两个视图均有独立版本，源码指纹由 `fingerprint.go` 计算并供平台锁定历史裁判。

## 确定性边界

`Init` 要求 Host 提供至少 32 字节秘密熵，不接受房间用户提交墙序或种子。先对秘密熵做 SHA-256，再通过 HMAC-SHA-256 标签分离初始座位、每手墙序和牌实例 ID。洗牌采用 Fisher–Yates 与拒绝采样，计数器使用大端 uint64。原始牌按万、筒、条、字、花构建；实体 ID 是单独派生的 96 位不透明值，不携带墙位置。

原始发牌为庄家起逆时针三轮每次四张，再每人一张，庄家再一张。之后按庄、下家、对家、上家完成各自全部起手补花。普通摸牌从墙头，杠补和花补从墙尾，二者相遇时墙耗尽。每手墙序独立派生，换圈采用规格中的固定换座表；累计分按稳定 participant ID 保存。

状态包含完整牌实例目录，但剩余墙只有 `[Head,Tail)`。历史弃牌被取用后只作历史引用，不算第二个物理持有区。每次加载快照核验 144 张牌的唯一归属、34 种普通牌各四张、八种花各一张、实体 ID 与牌种绑定及响应来源。

插件不读取系统时钟、数据库、网络或全局随机源。Host 收集意向并保持统一响应窗口；`resolve` 一次提供 `participant_id -> option_id`。和牌优先，其次碰/明杠，再次吃；同等级按来源后的行牌距离排序。第一合法意向锁定、命令幂等、控制权、窗口截止、崩溃恢复及牌谱授权由 Host 负责。

## 行动与时钟

`Inspect` 返回 `self`、`reaction`、`intermission` 或 `ended` 窗口。选项由手序、逻辑步数、座位、动作和实体牌派生；旧选项不能应用到新窗口。`action` 只用于本人行动，反应统一通过 `resolve`。`timeout` 自行行动优先合法和牌、补花、弃刚摸入牌、固定牌序弃牌；响应超时保留 Host 已登记的 `Choices`，其余视为过。

补花产生新快照、选项和决策 ID。Host **须保留原行动截止时间**，不能因连续补花无限延长行动。起手补花在初始化中完成，不开启额外行动时钟。

保留未补花牌可直接弃出，花牌弃牌不能吃碰杠和。暗杠只向本人提供牌面，终局才向同场参赛者核验；加杠先等待抢杠，成功后才移牌补牌。抢杠成功保留原碰，新增牌归和牌者。无振听、食替、连庄、即时杠分及四杠流局规则。

末张行为遵循 `om-mcr-1`：墙空时不能补花或开杠，最后摸牌后保留合法和牌/弃牌，最后弃牌只可和或过，再判荒牌。`standard_16` 必须打满四圈十六盘，不设线下 150 分钟整场上限；`practice_1` 与 `practice_4` 不产生标准名次积分。

## 计分与视图

番种计算仅调用 `scoring.Evaluate`，上下文由真实行牌状态生成。非花分至少 8 才生成和牌选项。花牌分只计已补入花区的花牌，不能用于凑 8。和绝张只统计当时已公开且去重的实体牌；暗杠不计作公开牌面。花补后的自摸不会沿用之前的杠上开花标签。

点和：和牌者 `24+F`，放铳者 `-(8+F)`，另两家各 `-8`。自摸：和牌者 `3*(8+F)`，三家各 `-(8+F)`。完整标准赛程的名次积分为 4、2、1、0，平分所占名次，使用有理数。

`Project` 只有两个授权入口：

- `participant_private`：验证稳定 participant ID，返回本人暗手、本人摸牌、规则允许的对手副露/花区；对手暗杠在行牌中没有牌面，终局可核验赢家成牌及所有暗杠。
- `spectator_discard_only`：使用独立白名单 DTO。唯一牌面字段是 `discards[].kind`。不返回任何实体牌 ID、手牌、副露牌面、花区、暗杠、赢家成牌、番种、合法动作、墙序或种子；手末、整场结束及回放不放宽。即使同时提供参赛者 ID 也不会升级此视角。

视图不会直接嵌入内部状态。`Transition.Events` 仅包含动作类型、座位和弃牌引用，不能替代受权投影或被用于广播原始快照。

## 验证

```sh
go test ./rules/mcr/...
go test ./rules/mcr -run '^$' -fuzz '^FuzzSnapshot$' -fuzztime=10s
MCR_SOAK_MATCHES=625 go test ./rules/mcr -run '^TestSoak$' -count=1 -v -timeout=30m
```

最后一条为 625 个独立秘密熵种子、每场十六盘，共 10,000 盘。每一步检查实体牌守恒，结算检查非花门槛和零和收支，每圈核对座位映射，周期性跨 JSON SDK 边界比较重放结果并核验观众白名单。固定规则牌例另覆盖抢杠、多人和优先级、七分加花不足起和、精确支付、暗杠保密与核验、四杠、手动弃花、连续补花及末张响应。

算番结果目前提供最佳番种表与分值，完整的逐牌组解释和未采纳番种原因不在底层库返回值中；不得把番种表宣传为已实现完整解释树。
